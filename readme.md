# 🐼 Entity Analyzer 🐾

**🚀 一键洞悉 Minecraft 世界的生物分布！**

这是一个 Spigot/Paper 插件，利用强大的 K-means 聚类算法，助你轻松掌握服务器内生物实体的分布情况。告别盲目探索，让数据指引方向！

## ✨ 核心功能

*   🎯 **实体聚类**:  精准分析生物实体位置，洞悉世界构成 (排除玩家)。
*   🔢 **自定义分析**:  自由设定聚类数量，满足不同分析需求。
*   📊 **直观呈现**:  GUI 界面清晰展示分析结果，一目了然。
*   📍 **瞬间传送**:  点击即可传送至集群中心，高效便捷。
*   🎇 **边界可视化**:  粒子特效动态展示集群范围，所见即所得。
*   🌟 **实体高亮**:  选中集群，发光效果即刻标记，不再遗漏。
*   🌐 **多语言支持**:  轻松切换语言，无障碍使用。

## 🛠️ 安装指南

1. ⬇️ **下载插件**: 前往 [你的下载链接 - 替换这里!] 下载最新 `.jar` 文件。
2. 📂 **放置插件**: 将文件放入服务器的 `plugins` 文件夹。
3. 🔄 **重启服务器**: 重启以加载插件。

## 🎮 使用教程

### 🕹️ 命令

*   `/analyzeentities [数量]` - 启动实体分析。
    *   不指定数量则使用插件默认值。
    *   指定数量可自定义聚类数量。

### 🗺️ 使用步骤

1. **执行命令**: 输入 `/analyzeentities` 开始分析。
2. **等待完成**: 稍作等待，插件将完成分析。
3. **查看结果**:  打开 GUI 界面，查看实体集群分布。
4. **互动操作**:
    *   点击物品传送至集群中心。
    *   观察高亮显示的实体和边界粒子。

## 💬 自定义消息

编辑 `plugins/EntityAnalyzer/message` 文件夹下的语言文件，即可自定义插件消息。

## ✅ 权限管理

*   `entityanalyzer.analyze`: 允许使用 `/analyzeentities` 命令 (默认 OP)。

## 🎯 为何使用 Entity Analyzer？

*   **📈 效率提升**: 快速定位生物聚集地，无需漫无目的寻找。
*   🔍 **问题排查**:  轻松发现异常的生物分布，例如刷怪塔故障。
*   🌍 **世界探索**:  更深入地了解你的 Minecraft 世界生态。
*   🛠️ **优化管理**:  辅助服务器管理员进行更精细化的管理。
